# Website redesigns

Redesigns of real local businesses — restaurants, a coffee shop, a wedding venue,
a running store. Static sites: hand-written HTML and CSS, no framework, no build
step, no dependencies.

Each one is an unsolicited concept redesign, built to be shown to the owner. They
are previews, not the businesses' live sites.

---

### [Wu's House](https://wus-house-preview.vercel.app/)
A Japanese hibachi and sushi restaurant group across Chicagoland and northwest Indiana.
Homepage source: [wus-house](wus-house/).

### [Wu's Korean BBQ](https://wus-korean-bbq-editorial.vercel.app/)
